Machine-learning architecture

From measurements to tomorrow’s estimate

The final estimator learns the next-day change, then adds that change to the current PM2.5 concentration.

  1. 01
    Acquire

    OpenAQ PM2.5 and NASA POWER weather

  2. 02
    Engineer

    Lags, rolling means, momentum and seasonality

  3. 03
    Learn ΔPM2.5

    Histogram gradient boosting with absolute-error loss

  4. 04
    Validate forward

    Five expanding chronological test windows

  5. 05
    Forecast

    Today’s value + predicted change = tomorrow

Prediction logic

PMt+1 = PMt + f(xt)

where f estimates the next-day change from the feature vector at day t

Responsible modelling

Useful as research evidence—not as a public-health alert.

Intended use
  • Educational analysis and reproducible experimentation
  • Short-horizon forecasting research
  • Prototype dashboard development
Known limitations
  • One Lahore monitoring station
  • Long periods of missing PM2.5
  • No direct traffic, fire, crop-burning or dust indicators
  • Sudden extreme spikes remain difficult
Next research step
  • Add multiple monitors and satellite aerosol data
  • Estimate prediction intervals
  • Build secure scheduled ingestion and retraining
