Data and modelling evidence

What the model actually learned from

01 · Sources

Measured pollution and weather

  • OpenAQ StateAir Lahore daily PM2.5
  • NASA POWER temperature, humidity, wind and precipitation
  • Station coordinates: 31.560078° N, 74.335890° E
02 · Preparation

Conservative missing-data treatment

  • 2,113 calendar days audited
  • Only gaps of three days or fewer interpolated
  • 46 values filled; 305 longer-gap values remained missing
03 · Features

Twenty time-aware predictors

  • PM2.5 lags, rolling means and variability
  • Weather levels, changes and precipitation totals
  • Pollution momentum and annual seasonality

Machine-learning pipeline

From observations to tomorrow’s estimate

The final estimator predicts the next-day change, which is added to the current PM2.5 concentration.

  1. 01
    Acquire

    OpenAQ PM2.5 and NASA POWER weather

  2. 02
    Engineer

    Lags, rolling means, momentum and seasonality

  3. 03
    Learn ΔPM2.5

    Gradient boosting with absolute-error loss

  4. 04
    Validate forward

    Five expanding chronological test windows

  5. 05
    Forecast

    Current value + predicted change = tomorrow

Prediction logic

PMt+1 = PMt + f(xt)

f estimates the next-day change from the feature vector at day t

Responsible interpretation

Research prototype, not a public-health alert

Appropriate use

Educational analysis, reproducible experimentation and short-horizon forecasting research.

Current limitations

One monitoring station, long missing periods, no traffic, crop-burning, dust or satellite aerosol indicators.

Next development

Multiple monitors, satellite variables, prediction intervals and scheduled data ingestion.
